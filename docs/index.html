Architecture & Design

Engineered for LLM Attention Efficiency

Why modern AI coding models generate 10x better code when prompted with CodeShave skeletons.

🎯

AST Tree Pruning

Strips loops, error handlers, and internal execution blocks to ... or { /* ... */ } while keeping 100% syntactically valid code structures.

🧠

Zero Attention Noise

Removes thousands of lines of boilerplate. Directs model attention entirely to public interfaces, contracts, schemas, and high-level architectural relationships.

One-Click Setup

Connect to Any Environment in Seconds

Choose your preferred AI client, IDE, or terminal workflow.

Run via pip & auto-connect to all installed assistants:
pip install codeshave codeshave connect --all
Or run instantly without installation via uvx:
uvx codeshave mcp

Install directly from the official marketplace or add to .vscode/mcp.json:

Marketplace Command or .vscode/mcp.json snippet:
{ "mcpServers": { "codeshave": { "command": "uvx", "args": ["codeshave", "mcp"] } } }
Open in Visual Studio Marketplace →
Claude Code (Terminal Assistant) — 1 command:
claude mcp add codeshave -- uvx codeshave mcp
Claude Desktop — Add to claude_desktop_config.json:
{ "mcpServers": { "codeshave": { "command": "uvx", "args": ["codeshave", "mcp"] } } }
Add to ~/.codex/config.toml (or simply run 'codeshave connect codex'):
[mcp_servers.codeshave] command = "uvx" args = ["codeshave", "mcp"]

Frequently Asked Questions

Everything you need to know about CodeShave and AST token compression.

What is CodeShave and how does it work?
CodeShave is a deterministic code context compressor and Model Context Protocol (MCP) server. When you provide code files or repositories to an AI model, CodeShave prunes loop contents, private logic, and execution statements down to minimal placeholders (like ... or { /* ... */ }). All classes, functions, decorators, type hints, docstrings, and interfaces remain 100% syntactically valid.
Does CodeShave cause the AI to hallucinate?
No — in fact, it significantly reduces hallucinations. Because all function signatures, argument types, return types, and docstrings are fully preserved, the LLM has exact interface contracts without being distracted or confused by hundreds of lines of implementation noise.
What programming languages are supported?
CodeShave natively supports Python, TypeScript, JavaScript, Go, Rust, Java, C#, C, C++, Kotlin, and Swift.
Is CodeShave an official Model Context Protocol (MCP) server?
Yes. CodeShave is an officially verified server on the Model Context Protocol (MCP) registry with package ID io.github.jaideepkrishna2008-ui/codeshave.
