# CodeShave for VS Code & Cursor

<p align="center">
  <b>High-speed AST code compressor & 1-click MCP server for AI coding assistants.</b><br>
  Reduces prompt context by <b>80% to 95%</b> while preserving 100% valid syntax, type annotations, and class hierarchies.
</p>

---

## ⚡ Features

- **1-Click MCP Server**: Automatically activates the `codeshave` MCP server in VS Code and Cursor with zero JSON configuration.
- **Context Menu Compression**: Right-click any file in the Explorer or active editor $\rightarrow$ **"CodeShave: Compress Current File to Clipboard"**.
- **Selection Compression**: Select a block of code, right-click $\rightarrow$ **"CodeShave: Compress Selection to Clipboard"**.
- **Status Bar Integration**: Instantly view compression status from the bottom status bar.
- **Universal Multi-Language Support**: Python, TypeScript, JavaScript, Go, Rust, Java, C/C++, C#, Kotlin, Swift, and more.

---

## 🚀 How to Use

1. **Compress File**: Right-click an open file $\rightarrow$ select `CodeShave: Compress Current File to Clipboard`.
2. **Compress Selection**: Highlight code $\rightarrow$ right-click $\rightarrow$ select `CodeShave: Compress Selection to Clipboard`.
3. **Configure MCP Server**: Press `Ctrl+Shift+P` (or `Cmd+Shift+P`) $\rightarrow$ run `CodeShave: Auto-Configure Local MCP Server`.
