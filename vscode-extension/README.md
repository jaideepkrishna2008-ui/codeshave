# CodeShave for VS Code & Cursor

High-speed AST code compressor and MCP server connector for VS Code, Cursor, Copilot, and Claude.

## Features
- **1-Click MCP Server**: Automatically activates the `codeshave` MCP server in Cursor and VS Code Copilot with zero JSON configuration.
- **Context Menu Compression**: Right-click any file or selection $\rightarrow$ **"CodeShave: Compress Current File to Clipboard"**.
- **90%+ Token Reduction**: Strips internal execution bodies while keeping 100% of class hierarchies, interfaces, types, and function signatures.
- **Status Bar Integration**: Quick access directly from the VS Code status bar.

## Installation
Search for **CodeShave** in the VS Code Extensions tab (`Ctrl+Shift+X`) and click **Install**.
