# CodeShave Plugin for Antigravity

High-speed AST code compressor and MCP server for Antigravity AI coding assistants. Reduces prompt tokens by 80% to 95% across all major programming languages while preserving 100% valid syntax, interfaces, and types.

## Features
- **MCP Server Included**: Provides `shave_code` and `shave_file` tools.
- **Polyglot AST Support**: Python, TypeScript, JavaScript, Go, Rust, Java, C++, C#, Ruby, Swift, and more.
- **Zero Hallucination Blueprint**: Models read precise signatures, types, and class hierarchies.
- **Context Multiplier**: Enables 50+ turn conversations without context exhaustion.

## Usage
Simply invoke `/codeshave` or ask Antigravity to explore/analyze any repository or large file.
